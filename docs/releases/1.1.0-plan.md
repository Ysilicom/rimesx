# 1.1.0 发布计划

范围：macOS、iOS、Android、Windows。Linux 保留现状。源码、构建、安装、实机体验、审核与公开发布分别验收。

## 顺序与证据

1. **已完成**：整合 PR #48 于 2026-10-04 合入主线 `29dfecc9764a31f648976de41acd7fed82d2f554`。macOS、iOS、Android、Windows、Linux 与 macOS 打包 CI 全部通过。
2. **已完成**：本体固定插件仓 `c64bc83` 和文件摘要，建立统一清单、平台别名、宿主能力及安装生命周期。原生实现由插件仓维护，随宿主编译；下载内容不装载任意可执行代码。
3. **已完成**：Polisher 的下载内容实际进入请求；校验摘要、安装后停用、显式启用与选择、停用/卸载取消、迟到结果拒绝、重装重新授权、旧用户离线保留及原文/配置保留均有测试。LaTeX 使用同一来源和指令通道。
4. **已完成**：四平台消费端与 Windows 并击均已接入并验证。24 个插件按平台提供：macOS 21 个（13 预装、8 下载），iOS/Android 各 6 个，Windows 3 个；保留手机快问、作诗、字符画，音乐目前仅 macOS。
5. **已完成本轮明确用例**：独立构建、打包、安装及设备验收记录见下表。广泛宿主兼容性、长时间使用、Intel 实机及 Windows 重启后日常使用不在本轮已通过范围内。
6. **交付中，iOS 真机复验通过**：macOS Developer ID 签名、公证和同包安装通过；Android 长期密钥签名及保留数据升级通过；Windows EXE 实际升级通过，插件重装修复已通过 x64/x86 检查及新 EXE 的 108 文件载荷校验。iOS 35 号因维护者报告震动回归，已撤回外部测试审核；38 号保留候选条右侧 Buffer、新增长按上滑符号开关和导入方案包删除，维护者确认慢打清晰、快打跟手，并明确验收通过。iOS 40 号和 Android code 12 统一更新设置首页 Logo 与两行品牌文案后重新打包。官方插件 [v1.1.0 已公开](https://github.com/scholay/rimes-plugins/releases/tag/v1.1.0)，本体尚未公开发布。

## 当前边界

- 统一 SDK 验证 11 类贡献；24 个插件声明平台适配。macOS 60 项 smoke、三种外观各 22 个设置页面、Shared 79 项测试、iOS 模拟器 163 项测试（1 项明确跳过）通过。Android 真机已通过插件生命周期、网络策略、发送权限、后端与设置界面测试；Windows x64/x86 各 17 项 CTest 与真实引擎/TSF 输入测试通过。
- Android API 地址、模型和密钥可配置，保留旧 CometAPI 配置；已使用 DeepSeek 官方接口在真机验证实际 SSE 回复，实际键盘快问、润色、翻译与取消/输入目标/隐私边界共 202 项断言通过。
- 所有预装/下载插件最终需支持统一启停与逻辑卸载，卸载保留用户数据；隐藏 Mailbox 终端入口不终止已接受的终端任务。
- 1.0 用户插件权限不能因迁移丢失；新安装插件不能自动启用、选中或发起请求。
- 维护工作在交付分支完成，保留原工作区。设备上旧版的可用体验不能作为 1.1.0 已验收证据。
- 本文是执行记录，不是公开发布公告；未完成项目不算已交付。
