## Implemented behavior

The native main app now follows the iOS grouped welcome/settings structure:
enablement and a separate typing playground; schemes, chord mappings, keyboard
layouts and 18 colors; resources, translation direction and AI Mock; data, privacy,
licenses and an explicit Android feature-status page. Light/dark styling and
Chinese/English labels follow the system. Keyboard previews draw the actual
ordinary/chord geometry and palette. The writing entry uses a writing symbol;
**26 pinned Lucide vectors** and their complete license are packaged. This is
source-backed layout/style work, not a claim of complete iOS pixel equivalence.

The settings model persists the ordinary schema, layout, theme, translation
direction, learning switch and AI Mock switch. Nine-key selection chooses Pinyin;
selecting a scheme exits chord mode, and a non-Pinyin scheme exits nine-key mode.
Chord selection retains the ordinary schema preference while using its built-in
Natural Code mapping. The mapping reader exposes all **427** entries without
editing/import controls. Nested license/mapping pages return to their actual
parent; page and navigation state survive activity recreation and rotation.

Scheme/layout changes apply as one compatible pair. The IME defers a change if
confirmed raw input cannot be delivered, preserving the draft for retry. Translation
direction changes revoke the previous translation result without consuming source
or discarding unrelated AI output. Disabling AI Mock cancels/revokes Mock work and
prevents execution while leaving dictionary translation available. These are actual
execution preferences, not presentation-only switches.

Home contains no typing fields. The playground has ordinary, secondary, password
and private fields; trial text is excluded from saved view/activity state and
preferences, and is cleared on reconstruction or leaving the page. Existing
offline Chinese input, local dictionary translation and labelled OpenAI-format
Mock execution remain as documented in dev.6. Real AI provider configuration,
custom imports, pet animations/rotation pools and typing statistics remain pending.
