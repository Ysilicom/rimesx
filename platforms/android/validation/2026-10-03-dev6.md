## Implemented behavior

Translation now uses a real bundled **CC-CEDICT** dictionary with `auto`, `zh-en`
and `en-zh` directions. Chinese lookup supports simplified/traditional headwords
and greedy longest phrases; English lookup supports case-insensitive ASCII words
and exact multiword phrases. Unknown words and supplementary code points remain
as typed, and partial matches are explicitly labelled. Zero-match input produces
an error with its source preserved. This is deterministic dictionary conversion,
**not contextual or neural sentence translation**; ambiguities and grammar are
not resolved by a language model.

The pinned [MDBG CC-CEDICT](https://www.mdbg.net/chinese/dictionary?page=cedict)
release is `2026-10-01T23:26:37Z`, with **125,166** source entries,
**183,491** Chinese index keys and **103,644** English reverse keys. The generated
radix index occupies **4,663,964 bytes**, with **10,578,032 bytes** of raw arrays/value
pools before object headers and transient lookup strings. Thirty English common
sense choices and two Chinese greeting forms are each verified against the
original definitions. Source/derived dictionary data retain
[**CC BY-SA 4.0**](https://creativecommons.org/licenses/by-sa/4.0/);
the APK includes the original source header, modification notice and full license.
The [source manifest](../resources/dictionary/cedict.lock.json)
records source/index/license hashes. The index SHA-256 is
`4dcd01007f78cb1d2857b51593cd6c70d22fa049446e5c4fee2a2a16806f5e8c`.
Loading occurs lazily on a worker, shares only immutable dictionary data, and
observes cancellation. No phone-side download, dictionary compilation or user
input history is added.

快问、润色、作诗 and 画画 now run through a **local OpenAI-format Mock**. Requests
use Chat Completions JSON (`model`, system/user `messages`, `stream: true`); replies
are deliberately fragmented UTF-8 SSE chunks, with `finish_reason: stop`, `[DONE]`
and EOF required before a result is sendable. The parser rejects incomplete or
malformed streams, invalid Unicode/UTF-8, trailing non-whitespace data and exceeded
bounds. `/v1/chat/completions` is transport metadata; no HTTP provider, credentials,
model inference or image generation is implemented. Visible replies identify
Mock, and their deliberate 40 ms chunk delays demonstrate streaming rather than
measure provider latency. Mock echoes at most 512 UTF-16 source units in its
fixed demonstration reply.

Plugin output appears in the upper Buffer row while the captured source remains
below. Run freezes the current source; editing, cancellation, plugin changes,
hide, selection/target retirement and private fields revoke stale results.
Partial output cannot be sent. A complete result is committed as one block only
after an explicit Send/Return; source acknowledgement requires framework acceptance of a commit
to the still-authorized target. Input and output are limited to **16,384 UTF-16
units**. Existing keyboard geometry, icons, layouts and native-engine libraries
remain from dev.5; this report covers the new execution/delivery behavior.
