# Learned-association management — iOS build 30

## Behavior

- Remove **Clear learned associations** from the keyboard gear menu, even when learned records exist.
- Add **RIMES app → 数据管理 / Data management → 清除联想学习记录 / Clear learned associations**. A separate alert explicitly offers Cancel and a red Clear records action, explains that deletion is irreversible, and limits the operation to learned word continuations.
- Confirming writes only an optional reset UUID into the existing app configuration. The keyboard applies it once on its next presentation. The app reports a saved request, not immediate deletion.
- Learned words remain at the existing keyboard-private `RIMESAssociations.json` path, excluded from backup. No learned text is moved into the App Group or read by the app.
- Reset acknowledgements stay in the keyboard's own preferences. A failed file deletion is not acknowledged; a controller holding pre-reset history cannot save it back over fresh learning. Reopening after the same request preserves newly learned records.
- No request is generated by an upgrade. Input schemes, dictionaries, key layouts and Buffer drafts are outside the clear operation.
