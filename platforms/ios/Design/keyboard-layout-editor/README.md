# 键盘布局编辑器 · 交互原型

用于确认自定义键盘的编辑方式，尚未接入 iOS 输入法或中文解码。

## 打开

在仓库根目录启动静态服务：

```sh
python3 -m http.server 8768 --bind 127.0.0.1 --directory platforms/ios/Design/keyboard-layout-editor
```

浏览器打开 `http://127.0.0.1:8768/`。页面使用本地 HTML、CSS 和 JavaScript，不依赖在线服务。
已保存布局属于当前浏览器和访问地址；换端口或浏览器不会自动携带数据，可用“导出配置”备份。

## 建议试用顺序

1. 选择 26 键模板，拖动两枚字母键交换位置。
2. 清空一个槽位，再从键位库放入字母或功能键。
3. 调整每行槽位数、行高、间距、左右分区和单键宽度，查看预览变化。
4. 切到“试打预览”，测试字母、空格、删除和回车。
5. 保存一个自定义名称，刷新后重新打开；试一下撤销、重做和恢复模板。
6. 切换 9／14／18 键模板，比较字母组的摆放方式。这些模板只演示布局，不生成中文候选。

原生接入阶段和验收标准见 [PLAN.md](PLAN.md)。
